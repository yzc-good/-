术语在线接入 · 调查记录（2026-10-24）
========================================

一、结论概览
------------
术语在线的「权威术语数据」具备官方接入通道，可直接拿到规范的
cn(中文名)/en(英文名)/subjectName(学科)/source(来源文献) 明文。
当前工具已完成「联网跳转术语在线查」入口（web v10），下一步
（可选）可通过官方 API 把术语库接入本地翻译/查词。

二、官方数据/接口通道（方案 A 依据）
------------------------------------
来源：术语在线官网「平台数据开放」栏目发布的官方 PDF
《术语在线服务接口使用规范》5 页（166KB）。

核心接口：
  GET https://api.termonline.cn/main-serve/business/tm/tmWord/appSearch

请求参数（form-data/header）：
  term        String  必填  查询关键词
  match       String  必填  1=精确 2=模糊
  pubYears    Array   必填  可传空
  appid       String  必填  查询凭证
  secret      String  必填  查询凭证
  pageNo      Integer 默认1 页码
  pageSize    Integer 默认10 每页量

返回（JSON）：
  result.totalRecords   结果数
  result.tmWordList[]:
    id / cn(中文名) / en(英文名, JSON数组字符串)
    subjectName(学科) / subjectFullName / publishYear(发布年)
    definition(定义) / source(来源,如《海峡两岸大气科学名词》)
    alsoName(又称) / commName(全称) / collect / tmVideo
  result.overView: en[] / cn[] / tw[](台湾名) / source[]

已实测：公开 web 站的同源 web 接口 allSearch 匿名访问返回空壳
分页容器（totalRecords=0），确认正式查询须带凭证 appid+secret。
开放接口域名 api.termonline.cn 走 appSearch。

三、凭证申请门槛（合规关键）
----------------------------
PDF 说明：向术语在线平台/管理员申请第三方调用凭证，须提供：
  · 申请单位名称
  · 统一社会信用代码
  · 用途说明
  · 联系人 + 手机号
  · 上传申请材料

即：需要「单位资质」才能拿 appid/secret。
- 若有单位主体 → 可正式申请，接入最正规（数据授权明确）。
- 若纯个人自用 → 拿不到单位凭证；但「跳转到术语在线网页查」
  不涉及自行抓取/再分发数据，完全合规，已经可用。

四、当前已落地（不依赖凭证的部分）
----------------------------------
手机版 + 桌面版均已在词典面板加「🔬 术语在线」按钮：
  · 点击用当前查词（或当前取词）自动填到术语在线搜索页
  · 术语在线搜索 URL 已验证可达（HTTP 200）
  · web 版本号已升至 10，含此功能

五、后续可选：把术语库接入本地（需用户决定是否以单位申请）
--------------------------------------------------------
若获得 appid/secret，可把官方返回的
  cn <-> en + subjectName + 学科+来源
叠加进现有词库（dict_multi.json），
让专业术语翻译优先采用「全国科技术语委标准译名」。
实现方式：类似 buildZhIndex 的术语索引，
命中术语词时优先展示标准译名与来源。

六、风险与合规提醒
------------------
· 术语在线的「数据」属全国科技术语委，接口有凭证访问控制。
· 商业/分发用途必须走官方申请获取授权，勿匿名爬取其数据。
· 当前「跳转网页」&「官方 API（若申请到）」两条路都合规；
  切勿绕开凭证抓 web 接口。
