                英语翻译助手 · 使用说明
══════════════════════════════════════════════════════════

【这是什么】
一个英语翻译小工具，两大核心功能：
  1) 逐行对照翻译 —— 一行英文在上，一行中文在下
  2) 取词翻译 —— 点击（或悬停）任意英文单词，
     在右侧弹出释义（音标/词性/释义/例句/同反义词）

【怎么打开（建议用启动器）】
  ★ 双击  启动工具(双击).bat  → 输入 2
    自动启动本地服务并打开 http://127.0.0.1:8338
    这样才能导入 PDF / Word、联网自动翻译、查未收录词。

  直接双击 EnglishTranslator.html 也可离线阅读与取词。

【取词即一键多义】
  点击任意单词，右侧会显示该词按词性分组的完整释义：
    · 每个词性一个色块徽章（如 n. / v. / adj.）
    · 同一词性下列出该词性的全部译法（一词多义）
    · 下方附音标、例句、同反义词（有此数据时）
  示例：查 run → 【v.】跑/管理/运转/播放… 【n.】跑步/旅程/一系列…
  词库约 2810 个多词性单词，其余单词也补全了更完整的单一译法。

【词库（本次扩到 6200+ 词，含一词多义）】
  当前词条总数：6215 个，全部经「一词多义」扩充，另有 41000+ 条词形变化。
  覆盖范围：
    · 考研 / 雅思 / 四六级核心词
    · 学术词表 AWL（论文、外刊高频）
    · 外刊·时政·国际关系（选举、制裁、外交等）
    · 科技·网络新词（算法、区块链、直播、网红、深度伪造等）
    · 理工·生物·医学·环境专业术语（原子、基因、疫苗、生态等）
    · GRE / 专八高阶词汇（如 ubiquitous、quixotic、ephemeral）
    · 日常生活具体名词（食物、动物、身体、服饰、家居、工具…）
  词形变化自动生成：复数、过去式、-ing、比较级等。

【查不到某个词怎么办】
  点到尚未收录的词时，右侧提供两种兜底：
    · 「🌐 联网翻译」—— 调用在线词典给出该词的多条释义
      （多义词会按词性完整列出，如 charge：v.充电/控告/收费 …，n.电量/费用 …）
    · 「📖 牛津在线词典」—— 打开牛津学习者词典该词页面

  提示：联网查询走「有道词典」，多义词按词性输出全部译法；断网时
  该按钮提示需先连接本地服务。

【导入自己的文档（支持 PDF）】
  点「选择文件」可选 .pdf / .docx / .txt / .md。
  勾选「导入时联网自动翻译」后：先秒出英文，后台逐句翻译。

【顶部横幅含义】
  ✅ 绿色：已连本地服务，可导入 PDF/Word。
  ⚠️ 黄色：离线文件方式打开，导入 PDF 前请先启动服务。
  ❌ 红色：服务没运行，请重新双击启动器。

【常见问题】
  1. 点“打开”但 PDF 没反应？→ 看顶部横幅，按提示用启动器打开。
  2. 中文一直“（待翻译）”？→ 当时没联网；英文和取词不受影响。
  3. 提示“未能提取到英文文本”？→ 多为扫描版（图片）PDF，需先 OCR。
  4. 服务怎么停？→ 关闭标题 "EngTrans Service" 的黑色窗口。
  5. 首次打开稍慢？→ 内置词库较大（约 1.8MB），首次加载约 0.1 秒。

【文件夹内容】
  EnglishTranslator.html   主工具（内置文章 + 6214 词词库）
  server.py / server.pyw   本地服务（解析 PDF/Word + 联网翻译）
  vendor\pypdf             随附 PDF 解析组件（无需联网安装）
  data\                    词库与双语对照数据（均在 D 盘）
  启动工具(双击).bat       一键启动器
  使用说明.txt             本说明

【安卓 / 鸿蒙平板版（独立 App，不用开电脑）】
  EnglishTranslator-v1.3.apk   装机包（约 4.2MB）

  装上后词典、取词、PDF/Word 解析都在平板本地完成，
  不依赖电脑；联网查词/翻译在平板联网时自动启用。

  ● 安装：把 apk 传到平板 → 点击安装 → 允许"外部来源"
  ● 升级：直接装新版覆盖旧版即可（包名与签名一致，数据不丢）

  ● App 内远程更新（v1.2 新增，v1.3 修复网络）：
      标题栏有「🔄 更新」按钮，点它即可在 App 内检查并下载最新内容。
      更新分两种（也可同时）：
        a) 应用内容热更新 —— 只下载新版界面/词库，免重装；
        b) 新版 App 整包安装 —— 下载 APK 后弹出系统安装。
      更新内容需发布方上传到仓库 update/ 目录（见发布脚本）。

  ● 关于"检查更新失败"（v1.3 已修复）：
      v1.2 只连 GitHub 官方地址，国内网络经常超时。
      v1.3 改为同时向多个地址请求（GitHub 官方 + 公共加速镜像），
      哪个先通用哪个，所以国内网络下也能正常检查更新。
      若仍失败，多为当前网络整体受限，换 Wi-Fi / 手机热点后重试即可。

  ● 已修复的问题（v1.1 / 说明沿用）：
      - 联网查词提示 "Failed to fetch" —— 原因是 App 内部页面
        受浏览器跨域(CORS)限制。v1.1 改为走系统原生网络通道，
        不再受该限制。
      - 有道接口现在会返回"近似词"（查 CBAM 会给出 campaign），
        已改为只接受同名词条，避免张冠李戴。
      - 整句自动翻译改为小批 + 间隔请求，减少被限流。

  ● 查不到词时怎么办：
      缩写/专有名词/新词（如 CBAM、LLaMA）词典往往不收录，
      点词典面板里的「必应词典 / 必应搜索」会用浏览器去查。

  ● 仍提示联网失败时自查：
      1) 平板是否已连 Wi-Fi / 移动数据（App 内会提示"当前离线"）
      2) 换个普通单词（如 bank）试联网查词，验证网络是否通

【远程更新 · 发布说明（给内容提供方/开发用）】
  在电脑端用下面命令一键生成可上传的更新文件：
     python publish_update.py
  会生成 publish_update\ 目录，含：
     update.json    更新清单（App 读取它判断有没有新版）
     web-*.zip      网页内容包（热更新用）
     ….apk          新版整包（需要时）
  然后把 publish_update\ 下所有文件上传到 GitHub 仓库
  的 update/ 目录（仓库：https://github.com/yzc-good/-）
  让平板能访问到：
     https://raw.githubusercontent.com/yzc-good/-/main/update/update.json
  上传后平板点「🔄 更新」即可自动下载。
  ★ 每次推送前请先把 mobile\www\index.html 用 build_mobile.py 重建，
    再按提示选“仅网页”或“同时整包”发布。
