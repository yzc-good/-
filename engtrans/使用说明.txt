                英语翻译助手 · 使用说明
══════════════════════════════════════════════════════════

【这是什么】
一个中英双向的翻译小工具，三大核心功能：
  1) 逐行对照翻译 —— 一行原文在上，一行译文在下
     · 导入英文 → 出中文；导入中文 → 出英文（自动识别方向，中英混排也支持）
  2) 取词翻译 —— 点击（或悬停）任意英文单词，
     在右侧弹出释义（音标/词性/释义/例句/同反义词）
  3) 词典查词 —— 面板顶部输入框，输入英文或中文都能查
     · 输入 extinction → 全部义项；输入 灭绝 → disappear/vanish/extinction
     · 中文查英文走本地词库，**不用联网**
  4) 🔬 术语在线权威术语（联网）
     · 查词时自动查「全国科技术语委·术语在线」
     · 命中就显示：标准中英译名 + 学科 + 《来源名词》 + 术语编号 + 完整定义
       例：biodiversity → 生物多样性，《农学名词》2025，编号 06.005
     · 作为「权威参考卡」附在词典结果里，不覆盖通用释义
     · 面板顶部绿色「术语在线」按钮可一键跳官网看完整词条
  5) 🔊 听力朗读（边看边听）
     · 导入文章后，上方播放条点「▶ 朗读全文」，逐句朗读
     · 读到哪句，哪句自动高亮并滚到视野中间
     · 勾选「读译文」→ 每句先读英文再读中文；取消则只读英文
     · 「循环」反复播放全文；语速 0.5x–1.5x 可调
     · **点某一句 = 只朗读这一句**（读完就停，不往下读）
         · 点句子的空白处或黄色译文区域即可
         · 点蓝色英文单词仍然是取词，不会触发朗读，两者不冲突
     · 「▶ 朗读全文」= 从头连读到末尾
     · ⏮⏭ 的作用随模式走：
         · 单读模式（刚点过某句）→ 单读上一句/下一句
         · 连读模式（按过「朗读全文」）→ 跳转后继续连读
     · 双引擎自动切换：
         · 平板有系统语音包 → 用系统语音，**离线也能读**
         · 平板没有（如部分鸿蒙/Android WebView）→ 自动改用**在线语音**（需联网）
     · 右上角会显示当前用的是「系统语音就绪」还是「在线语音（需联网）」

【怎么打开（建议用启动器）】
  ★ 双击  启动工具(双击).bat  → 输入 2
    自动启动本地服务并打开 http://127.0.0.1:8338
    这样才能导入 PDF / Word、联网自动翻译、查未收录词。

  直接双击 EnglishTranslator.html 也可离线阅读与取词。
  注意：直接打开时「联网翻译」与「中文查未收录词」需要本地服务，
  本地词典取词和中文反查英文不受影响。

【取词即一键多义】
  点击任意单词，右侧会显示该词按词性分组的完整释义：
    · 每个词性一个色块徽章（如 n. / v. / adj.）
    · 同一词性下列出该词性的全部译法（一词多义）
    · 下方附音标、例句、同反义词（有此数据时）
  示例：查 run → 【v.】跑/管理/运转/播放… 【n.】跑步/旅程/一系列…
  词库约 2810 个多词性单词，其余单词也补全了更完整的单一译法。

【查不到某个词怎么办】
  点到尚未收录的词时，右侧提供两种兜底：
    · 「🌐 联网翻译」—— 调用在线词典给出该词的多条释义
      （多义词会按词性完整列出，如 charge：v.充电/控告/收费 …，n.电量/费用 …）
    · 「📖 牛津在线词典」—— 打开牛津学习者词典该词页面

  提示：联网查询走「有道词典」，多义词按词性输出全部译法；断网时
  该按钮提示需先连接本地服务。

【导入自己的文档（支持 PDF）】
  点「选择文件」可选 .pdf / .docx / .txt / .md。
  勾选「导入时联网自动翻译」后：先秒出英文，后台逐句翻译。

【顶部横幅含义】
  ✅ 绿色：已连本地服务，可导入 PDF/Word。
  ⚠️ 黄色：离线文件方式打开，导入 PDF 前请先启动服务。
  ❌ 红色：服务没运行，请重新双击启动器。

【常见问题】
  1. 点“打开”但 PDF 没反应？→ 看顶部横幅，按提示用启动器打开。
  2. 中文一直“（待翻译）”？→ 当时没联网；英文和取词不受影响。
  3. 提示“未能提取到英文文本”？→ 多为扫描版（图片）PDF，需先 OCR。
  4. 服务怎么停？→ 关闭标题 "EngTrans Service" 的黑色窗口。
  5. 首次打开稍慢？→ 内置词库较大（约 1.8MB），首次加载约 0.1 秒。

【文件夹内容】

【安卓 / 鸿蒙平板版（独立 App，不用开电脑）】
  EnglishTranslator-v1.6.apk   装机包（约 4.2MB）

  装上后词典、取词、PDF/Word 解析都在平板本地完成，
  不依赖电脑；联网查词/翻译在平板联网时自动启用。

  ● 安装：把 apk 传到平板 → 点击安装 → 允许"外部来源"
  ● 升级：直接装新版覆盖旧版即可（包名与签名一致，数据不丢）

  ● 中英双向互译（v1.4 新增）：
      以前只能「英文文档 → 中文」。现在两个方向都行，不用手动切换：
        · 导入英文（PDF / Word / TXT）→ 生成中文译文
        · 导入中文（PDF / Word / TXT）→ 生成英文译文
        · 中英混排的文档也能处理，逐行自动判断方向
      显示方式：第一行是原文，第二行（黄底）是译文。
      英文那一行里的单词仍然可以点一下查词典。
      提示：解析完后，状态栏会显示识别结果，例如「中→英 42 行」。

  ● 词典内查词（网页 v9 新增，支持中英双向）：
      词典面板顶部多了一个输入框，也可以点右上角「🔍 查词」直接打开。
        · 输入英文（如 extinction）→ 给出音标 + 按词性分组的全部义项
        · 输入中文（如 灭绝）→ 反查英文单词（disappear / vanish / extinction），
          每个词都列出完整义项，一词多义全能看全
      中文反查走本地词库（34418 条索引），**不用联网**；
      本地查不到时才联网翻译，且会先译成英文再回查词条。

  ● 手机竖屏取词（网页 v8 起为「跟随单词的浮动小窗」）：
      以前手机竖屏时词典被排在文章最下方，点词后要一路滚到底才能看释义。
      现在：
        · 不取词时，词典完全隐藏，不占视野；
        · 点任意英文单词，词典小窗浮到**这个词的正下方**
          （下方空间不够时会自动翻到词的上方）；
        · 小窗默认占 30% 屏高，释义在窗内滚动；
        · 顶部拖动条可上下调整大小，拖得太矮就收起；
        · 点右上角 ✕ 或点正文空白处也能收起；
        · 阅读位置不会跳动，收起后接着读即可。

  ● 关于「联网翻译失败」（v1.6 修复）：
      原文只能走 MyMemory 一个通道，而它有按 IP 的每日免费额度，
      用超了就返回 429，看起来像"没网"。
      v1.6 起改为三个通道依次尝试：
        1) 有道整句翻译（国内直连、无需密钥）—— 首选
        2) MyMemory（额度用完会跳过）
        3) Google（国内一般不通，仅作最后兜底）
      并且失败提示会区分原因，例如「额度已用完，请明天再试」
      或「接口超时，请检查网络」，不再是笼统的"可能无网络"。

  ● 翻译速度与限流（网页 v6 起）：
      有道接口大约每分钟只能调用 6 次，所以现在把多句合并成一次请求
      （每批最多 12 句、800 字符），22 句通常 3 次请求、1 秒内翻完。
      文档很长时若触发频率限制，App 会自动等待并接着翻，
      不会像以前那样翻到一半就停（以前 22 句只出 16 句）。
      ● 界面会实时显示「已完成 X / Y 句」。

  ● 关于「下载新版 App 失败：清单里没有整包升级信息」（v1.5 已修复）：
      原因：之前的一个加速镜像（jsDelivr）有最长 7 天的缓存，
      它会返回过期清单，导致「检查说有新版、真下载却说没有」。
      v1.5 已移除该镜像，换成 4 个每次都回源的直通代理
      （raw / ghfast.top / ghproxy.net / gh-proxy.com），
      并且「检查」拿到的清单会直接用于后续下载，不再二次拉取。

  ● 关于翻译质量与网络（重要）：
      「生成译文」这一步必须联网，离线时只能看原文。
      整篇翻译要逐句请求，长文档耗时较长，请耐心等待。
      若中途提示失败，多为网络或接口限流，稍后重试即可。

  ● App 内远程更新（v1.2 新增，v1.3 修复网络）：
      标题栏有「🔄 更新」按钮，点它即可在 App 内检查并下载最新内容。
      更新分两种（也可同时）：
        a) 应用内容热更新 —— 只下载新版界面/词库，免重装；
        b) 新版 App 整包安装 —— 下载 APK 后弹出系统安装。
      更新内容需发布方上传到仓库 update/ 目录（见发布脚本）。

  ● 关于"检查更新失败"（v1.3 已修复）：
      v1.2 只连 GitHub 官方地址，国内网络经常超时。
      v1.3 改为同时向多个地址请求（GitHub 官方 + 公共加速镜像），
      哪个先通用哪个，所以国内网络下也能正常检查更新。
      若仍失败，多为当前网络整体受限，换 Wi-Fi / 手机热点后重试即可。

  ● 已修复的问题（v1.1 / 说明沿用）：
      - 联网查词提示 "Failed to fetch" —— 原因是 App 内部页面
        受浏览器跨域(CORS)限制。v1.1 改为走系统原生网络通道，
        不再受该限制。
      - 有道接口现在会返回"近似词"（查 CBAM 会给出 campaign），
        已改为只接受同名词条，避免张冠李戴。
      - 整句自动翻译改为小批 + 间隔请求，减少被限流。

  ● 查不到词时怎么办：
      缩写/专有名词/新词（如 CBAM、LLaMA）词典往往不收录，
      点词典面板里的「必应词典 / 必应搜索」会用浏览器去查。

  ● 仍提示联网失败时自查：
      1) 平板是否已连 Wi-Fi / 移动数据（App 内会提示"当前离线"）
      2) 换个普通单词（如 bank）试联网查词，验证网络是否通

【远程更新 · 发布说明（给内容提供方/开发用）】
  在电脑端用下面命令一键生成可上传的更新文件：
     python publish_update.py
  会生成 publish_update\ 目录，含：
     update.json    更新清单（App 读取它判断有没有新版）
     web-*.zip      网页内容包（热更新用）
     ….apk          新版整包（需要时）
  然后把 publish_update\ 下所有文件上传到 GitHub 仓库
  的 update/ 目录（仓库：https://github.com/yzc-good/-）
  让平板能访问到：
     https://raw.githubusercontent.com/yzc-good/-/main/update/update.json
  上传后平板点「🔄 更新」即可自动下载。
  ★ 每次推送前请先把 mobile\www\index.html 用 build_mobile.py 重建，
    再按提示选“仅网页”或“同时整包”发布。
